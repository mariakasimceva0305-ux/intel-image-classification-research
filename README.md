# Классификация сцен: CNN и transfer learning

Сравнение небольшой CNN с нуля и ResNet18 с ImageNet-весами: замороженный backbone, частичное и полное дообучение. Данные — шесть классов Intel Image Classification.

## Протокол

Train/validation/test: 4902/2101/2997 изображений. Ещё 7003 изображения не используются, чтобы ограничить обучение на CPU. Удалены точные байтовые дубликаты и объекты с противоречащими метками; тестовые хеши исключены из обучающего пула. Визуально близкие изображения отдельно не фильтровались.

Размер входа 128 px, четыре эпохи, batch size 32. Checkpoint выбирается по validation macro-F1. Все шесть заранее заданных запусков завершены до оценки test. Статистики BatchNorm замороженных слоёв не обновляются. Seed 42 сравнивает четыре режима; полное дообучение дополнительно проверяется с seed 43 и 44.

## Результаты

Test macro-F1: CNN — 0,7100; frozen ResNet18 — 0,9013; частичное дообучение — 0,9172. Полное дообучение: 0,9204 / 0,9147 / 0,9115, среднее 0,9155 ± 0,0045 (выборочное стандартное отклонение).

По validation в основном сравнении выбран частичный fine-tuning. Лучший test-результат полного fine-tuning не используется для изменения выбора. Одинаковое число эпох не означает одинаковое время вычислений.

## Запуск

Python 3.12; версии — `environment.json`. Используются CPU-версии PyTorch 2.10.0 и torchvision 0.25.0. [Датасет](https://www.kaggle.com/datasets/puneet6060/intel-image-classification) разместите в `data/` по структуре `results/split_manifest.csv`.

```text
python train.py
python -m pytest -q test_pipeline.py
python predict.py --checkpoint results/partial_s42.pt --image path/to/image.jpg
```

Для независимого повторения задайте новую выходную папку: `python train.py --help`. Исходные изображения и checkpoint не включены в Git; веса создаются при обучении. Инференс использует сохранённый checkpoint без повторной загрузки ImageNet-весов.
